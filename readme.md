# Ntlas QR Generator - تجربة بصرية سينمائية 🚀

نظام متطور لتوليد رموز QR يعتمد على هوية بصرية غامرة (Cinematic UI) تدمج بين الفيديو والشفافية الزجاجية.

## 🌟 اللمسات الفنية والتركيز
- **خلفية فيديو إعلانية:** استخدام فيديوهات ترويجية عالية الجودة في القسم العلوي.
- **الهوية البصرية:** شعار "Ntlas" مع تأثير التوهج النيوني (Cyan Glow).
- **نمط الزجاج (Glassmorphism):** واجهة مستخدم تعتمد على `backdrop-filter` لتوفير عمق بصري حديث.
- **الفلسفة البرمجية:** التصميم يجسد شعار "1+1≠2" من خلال كسر القواعد التقليدية للواجهات.

## 🛠 المواصفات التقنية
- **اللغات:** HTML5, CSS3 (Custom Variables), JavaScript.
- **المكتبات:** `QRCode.js` للتوليد الفوري.
- **التواصل:** زر واتساب عائم ومدمج (+22230726475).
